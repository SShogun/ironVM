# M0 — KVM Bootstrap Evidence

## ABI contract

- `KVM_API_VERSION` is `12`; IronVM must reject any other value.
- `KVM_GET_API_VERSION` is `_IO(KVMIO, 0x00)`, with `KVMIO` equal to `0xAE`.
- M0 requires only opening `/dev/kvm`, querying the API version, reporting contextual errors, and closing the system file descriptor.
- Planned later ioctl surface: `KVM_CREATE_VM`, `KVM_SET_USER_MEMORY_REGION`, `KVM_CREATE_VCPU`, `KVM_GET_VCPU_MMAP_SIZE`, `KVM_GET_SREGS`, `KVM_SET_SREGS`, `KVM_SET_REGS`, and `KVM_RUN`.
- Planned later UAPI structures: `kvm_userspace_memory_region`, `kvm_regs`, `kvm_sregs`, and `kvm_run`.

## Authoritative references

- [Linux KVM API documentation: `KVM_GET_API_VERSION`](https://docs.kernel.org/virt/kvm/api.html#kvm-get-api-version) states that the ioctl returns version 12 and applications should reject other values.
- [Linux UAPI `include/uapi/linux/kvm.h`](https://github.com/torvalds/linux/blob/master/include/uapi/linux/kvm.h) defines `KVM_API_VERSION 12`, `KVMIO 0xAE`, and `KVM_GET_API_VERSION _IO(KVMIO, 0x00)`.
