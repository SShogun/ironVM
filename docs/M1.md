# M1 — First guest reaches HLT

## Current gate status

**PASS.** The guest was executed through the host's `/dev/kvm` device and returned `KVM_EXIT_HLT`.

## Scope implemented

- `System.NewVM()` creates one default VM, maps 64 KiB of anonymous host memory, registers slot 0 at GPA 0, and records the kernel-provided vCPU mapping size.
- `VM.LoadGuest()` copies bytes into guest RAM with bounds checks.
- `VM.NewVCPU(0)` creates one vCPU and maps its `kvm_run` area using the size returned by `KVM_GET_VCPU_MMAP_SIZE`.
- `VCPU.ConfigureRealMode(0)` preserves the vCPU reset state, sets CS base/selector to zero, RIP to zero, and RFLAGS to `0x2`.
- `VCPU.Run()` enters the guest once and returns the kernel exit reason.
- `TestGuestHLTExitsWithKVMExitHLT` loads the single-byte HLT instruction (`0xF4`) and asserts `KVM_EXIT_HLT` (`5`).

## Evidence

- **RED observed:** before VM/vCPU implementation, the focused test failed to compile at the missing `System.NewVM` method.
- **Host:** Linux/amd64, kernel `7.2.9-arch1-1`, Go `go1.27.1`; `/dev/kvm` is available to the elevated test process.
- **Focused integration test:** `GOCACHE=/tmp/ironvm-gocache go test ./internal/kvm -run '^TestGuestHLTExitsWithKVMExitHLT$' -count=1 -v` passed without a skip. It loaded `0xF4`, ran vCPU 0, and asserted exit reason 5.
- **Full suite:** `GOCACHE=/tmp/ironvm-gocache go test -count=1 ./...` passed uncached, including the real KVM integration test.
- **Static analysis:** `GOCACHE=/tmp/ironvm-gocache go vet ./...` passed.
- **ABI review:** independent review compared ioctl encodings and Go layouts against `/usr/include/linux/kvm.h` and `/usr/include/asm/kvm.h`. The review caught and corrected `KVM_GET_SREGS` to `0x8138AE83`; independent recheck confirmed the correction. The reported sizes are 32 bytes for the memory region, 144 for `kvm_regs`, 312 for `kvm_sregs`, 24 for a segment, and 16 for a descriptor table. `kvm_run.exit_reason` is at offset 8.
- **Whitespace/format:** `git diff --check` and `gofmt` check passed.

## Gate verdict

All M1 criteria are satisfied: the RED was observed, raw guest code executed under KVM and exited with `KVM_EXIT_HLT`, guest RAM backing and `kvm_run` sizing follow the UAPI contract, targeted and full tests passed, `go vet ./...` passed, and the independent ABI/unsafe review has no remaining blocker. M1 is complete; M2 may begin.
